# Inventory Management System

A personal project implementing a full-featured inventory management system using vanilla PHP and JavaScript. The system provides essential functionalities such as product tracking, stock management, and an intuitive user interface.

## Features

- Add, edit, and delete inventory items  
- Real-time stock updates  
- Search and filter products  
- Responsive design for various devices  
- User-friendly interface designed based on Figma mockups

## Technology Stack

- PHP (vanilla)  
- JavaScript (vanilla)  
- MySQL or MariaDB (for database)  
- HTML5 & CSS3
- BS5  

## Design

The UI/UX design is based on detailed wireframes and prototypes created using [Figma](https://www.figma.com/design/cfGP1KuWoYakYvDYhh9YIG/BM-Digital-Services-UI-UX?node-id=0-1&t=HTkXIVgyep9m2zB1-1).
